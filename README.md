# 📊 Data Analysis & Visualization Program

## 🌟 Project Overview

Welcome to the **Data Analysis & Visualization Program**! 📈

This project is a Python-based application designed to perform basic **data analysis, data exploration, data cleaning, descriptive statistics, and data visualization**.

The program provides an easy-to-use menu where users can select different operations and analyze a CSV dataset interactively. 🐍📊

---

## 🎯 Project Objectives

The main objectives of this project are:

* 📂 Load and work with CSV datasets
* 🔍 Explore and understand data
* 📋 Perform DataFrame operations
* 🧹 Handle missing values
* 📊 Generate descriptive statistics
* 📈 Create different types of visualizations
* 💾 Save generated visualizations as image files
* 🖥️ Provide an interactive menu-driven interface

---

## 🛠️ Technologies Used

### 🐍 Python

Python is used as the main programming language for developing the project.

### 🐼 Pandas

Pandas is used for:

* Creating DataFrames
* Reading CSV files
* Exploring datasets
* Sorting and filtering data
* Handling missing values
* Generating descriptive statistics

### 📉 Matplotlib

Matplotlib is used to create different graphical visualizations such as:

* 📊 Bar Plot
* 📈 Line Plot
* 🔵 Scatter Plot
* 🥧 Pie Chart
* 📊 Histogram
* 📚 Stack Plot

The project imports Pandas, Matplotlib and OS modules.

## ⚙️ Main Features

### 1️⃣ Load Dataset 📂

Users can provide the path of a CSV file and load the dataset into the program.

The program also handles the situation where the specified file cannot be found.

---

### 2️⃣ Explore Data 🔍

Users can explore the dataset through different options:

* 👀 Display the first 5 rows
* 🔚 Display the last 5 rows
* 🏷️ Display column names
* 🔤 Display data types
* ℹ️ Display basic dataset information

These options help users understand the structure and contents of their data.

---

### 3️⃣ DataFrame Operations 📊

The project provides several DataFrame operations:

* 📐 Display dataset shape
* 🏷️ Display columns
* 🔃 Sort data according to sales
* 🔎 Filter data based on sales values

These operations make it easier to analyze specific parts of the dataset.

---

### 4️⃣ Handle Missing Data 🧹

The program provides different options for dealing with missing values:

* 🔍 Find rows containing missing values
* ➗ Fill missing numeric values using the mean
* 🗑️ Remove rows containing missing values
* ✏️ Replace missing values with a specific value

This helps improve the quality and usability of the dataset.

---

### 5️⃣ Descriptive Statistics 📈

The program can generate descriptive statistics for the dataset.

This provides a quick statistical overview of the available numerical data.

---

## 📊 Data Visualization

The project supports **six different visualization types**. 🎨

### 📊 1. Bar Plot

A bar plot is used to compare values between different categories.

Users can select the columns for the X-axis and Y-axis.

---

### 📈 2. Line Plot

A line plot is useful for showing changes or trends between data points.

The program allows users to select the X-axis and Y-axis columns.

---

### 🔵 3. Scatter Plot

A scatter plot is useful for displaying the relationship between two numerical variables.

Users can select the required X-axis and Y-axis columns.

---

### 🥧 4. Pie Chart

A pie chart represents the distribution of categorical values as parts of a whole.

The user can select a column for creating the chart.

---

### 📊 5. Histogram

A histogram displays the frequency distribution of numerical data.

The program creates the histogram using the selected column.

---

### 📚 6. Stack Plot

A stack plot displays multiple numerical datasets together and helps compare their values across indexes.

The project uses numerical columns for generating the stack plot.

---

## 💾 Save Visualization

After creating a visualization, users can save the generated plot by providing a file name, for example:

**scatter_plot.png** 🖼️

If no visualization has been generated, the program informs the user that no visualization is available.

---

## 🖥️ Menu Options

The main program provides the following menu:

1. 📂 Load Dataset
2. 🔍 Explore Data
3. 📊 Perform DataFrame Operations
4. 🧹 Handle Missing Data
5. 📈 Generate Descriptive Statistics
6. 🎨 Data Visualization
7. 💾 Save Visualization
8. 🚪 Exit

The program continues running until the user selects the Exit option.
